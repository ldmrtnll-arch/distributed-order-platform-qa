# Evidence Index

The repository keeps consolidated Markdown evidence rather than committing large generated reports or screenshots.

* Local K6 JSON summaries and captured service logs: `artifacts/performance/` (ignored).
* Local Playwright HTML: `playwright-report/` (ignored).
* CI normal/event Playwright reports: workflow artifacts retained for 10 days.
* CI K6 summaries/service logs: workflow artifacts retained for 10 days.
* Selected final metrics: [Performance Report](../performance-report.md).
* Full suite outcomes: [Test Execution Report](../test-execution-report.md).

Workflow configuration is versioned; this index does not claim a remote run result.
